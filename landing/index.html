Workspaces & panels

One workspace per project, organized into groups, with tabs inside — and any tab splits into as many resizable panels as you need, a minimum size keeping nothing from collapsing. Pin a workspace to keep it on top, zoom any panel to fill its tab, and the sidebar shows each tab's working folder live — open ports on hover.

Embedded terminal

A real terminal surface — colors, cursor movement, alternate screen — so vim, htop and fzf render exactly right. Every panel opens your own shell ($SHELL; PowerShell on Windows).

Agent status & notifications

umux reads the standard OSC signals emitted by AI CLIs (Claude Code, Codex, Gemini CLI, Aider…) and pings you when a task finishes — or when it's waiting for your input. Each panel shows a live status — working, needs-attention, idle — and the notification drops you onto the exact panel that raised it. Detection is from escape sequences and process names, never from your terminal content.

Sessions that outlive the window

umux Storestation — an optional daemon, off by default — owns your sessions: close every window and the shells keep running, so an agent halfway through a task keeps going. umux attach opens a view back into the live sessions, minutes or hours later.

Always-On (umux Core & Core Session)

One switch and the machine itself stays awake for as long as Core holds it — even with the lid closed and every window shut. On a Mac the switch is Core Session instead: umux core-session start 2h holds the same promise for a bounded window, then releases itself and pings you. The screen may still sleep, and where the OS limits the promise (battery, the lid) umux says so in plain words instead of pretending. Off by default.

In-app updates

umux checks GitHub Releases quietly on startup and updates itself with one click — download, apply, relaunch. Update bundles are signature-verified, so a tampered or unsigned bundle is rejected outright.

Session restore

Close the app, come back tomorrow: your workspaces, tabs and panel layouts are restored exactly as you left them.

Import from cmux

Moving over from cmux? One command — umux import cmux — or the in-app wizard carries your workspaces, groups, working directories and tabs across. Nothing is overwritten: colliding names get a from cmux suffix, and cmux's own files stay read-only.

Live CLI

The same umux command also controls the running app. Every layout change, terminal write, update check and window action takes effect live, as soon as you run the command. It all goes over one local socket. There is no auth and no network listener, so nothing is reachable from the network. For scripts and agents, umux agent-context prints the whole surface as one machine-readable document they can read to see what is available.

Install the CLI

Prefer the terminal? This drops the umux command-line tool into ~/.local/bin — it reads and writes the same store as the desktop app.

sh 
$ curl -fsSL https://raw.githubusercontent.com/CrystalPlatforms/umux/main/install.sh | sh

Look before you leap: append -- --dry-run to preview what it would do. Since v1.8.0 the CLI drives the running app live too — see the Live CLI tile below. macOS and Linux (x86_64). The desktop installers already carry the CLI too — details in the README.

First run — unsigned builds

umux is free & open source and ships without a paid code-signing certificate, so your system may ask for confirmation once:

  • macOS: right-click the app → Open, or System Settings → Privacy & Security → Open Anyway.
  • Windows: on the SmartScreen prompt choose More info → Run anyway.
  • Linux: AppImage needs chmod +x once; .deb/.rpm install normally.
